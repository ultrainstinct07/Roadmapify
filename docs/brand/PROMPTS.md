# Artwork generation prompts

Created with the built-in image generation tool. The PNGs are the generated originals; logo variants have transparent backgrounds. These prompts document creative intent, not a claim of exact color or pixel reproduction.

## logo.png

Use case: logo-brand. Asset type: GitHub public repository logo for roadmapify, a developer CLI for phased plans and durable decision memory. Create a polished minimal geometric standalone symbol: one continuous rising route with three circular milestone nodes, bending in a subtle lowercase r silhouette and ending at a small four-point north star. Strong clean silhouette, precise consistent strokes, flat ink navy and vivid mint, no gradients, no shadows, no lettering, no mockup. Center the single large symbol on a plain warm ivory square background with generous clear space. Modern understated open-source developer tooling identity. Output one square image.

## logo-dark.png

Use case: logo-brand. Edit the supplied roadmapify logo into its dark-background variant. Preserve exactly the route silhouette, three milestone circles, north-star shape, proportions and placement. Change the navy route to warm ivory #F7F5EE, keep the milestone centers and star mint #5BE3B0, and place the whole mark on a solid ink navy #102A33 square background. Flat solid colors, crisp edges, no lettering, no gradients, no shadows, no additional objects. This must be recognizably the identical brand mark.

## hero.png

Use case: illustration-story. Asset type: wide README hero illustration for roadmapify, an open-source CLI that preserves phased build plans and decisions across lost chat context. Editorial technical illustration, panoramic 3:1 composition. A graceful continuous mint route travels left to right over a dark ink navy field, linking three precise architectural stacks of ivory index cards and milestone nodes, and arriving at a luminous small four-point north star on the right. The cards contain restrained abstract lines, tiny connected nodes, and archived decision tabs, suggesting a plan and durable memory, not a real UI screenshot. Fine blueprint guide lines, sophisticated flat/isometric vector-like aesthetic with subtle grain, ample negative space, crisp shapes, quiet confident mood. Palette navy #102A33, mint #5BE3B0, ivory #F7F5EE with sparing amber #E9B45B. No text, no letters, no numbers, no watermark, no robots, no brains, no glossy 3D. One cohesive polished banner illustration.
